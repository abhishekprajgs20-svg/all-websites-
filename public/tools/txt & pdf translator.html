⚙️ Kaise kaam karta hai?

  • TXT mein original line breaks/blank lines rakhta hai. PDF mein page-wise text extract karta hai aur two-column pages par left-to-right reading order ka andaza lagata hai.
  • Q1., Q2., Ex:, 😂, ✅, (A)/(B)/(a)/(b), standalone numbers aur symbols ko protect karne ki koshish karta hai.
  • Bulk: saari files line se (ek ke baad ek) translate hoti hain. Har file ki row mein alag TXT/PDF download hai; “Download All TXT” sabhi ko alag-alag save karta hai (browser “multiple downloads allow” puchh sakta hai) aur ZIP mein saari translated TXT files ek archive mein aati hain. PDF per-file hi banti hai.
  • Auto-detect: file load hote hi source language pehchani jaati hai (aap manually bhi chun sakte hain). Target mein koi bhi language chunein; ⇄ button se From/To swap hota hai. Arabic, Urdu, Hebrew jaisi RTL languages sahi direction mein dikhti hain.
  • Multiple lines ko ek request mein batch karta hai aur kuch batches parallel chalata hai, taaki translation tez ho.
  • PDF export translated text se ek nayi, printable PDF banata hai. Yeh original PDF ke images, diagrams, exact fonts ya page layout ko bilkul same nahi rakhta. Scanned/image-only PDF ke liye OCR chahiye, jo is version mein nahi hai.
  • Translation Google Translate ke public, unofficial web endpoint se hota hai. Yeh free hai, lekin Google ki service badalne ya rate limit karne par fail ho sakta hai.

Important: koi bhi automatic translator 100% perfect matra/grammar ki guarantee nahi de sakta. Exam content mein names, facts, legal terms aur answer keys ko ek baar review zaroor karein. Original file ko tool overwrite nahi karta. PDF ke text extraction mein columns/tables ka order complex PDFs mein imperfect ho sakta hai; download se pehle preview check karein.
